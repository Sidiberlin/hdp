# Chatbot für Handbuch der Projektförderung

Der Ordner `/app` enthält den neuesten Stand der „BlueSpice HDP edition“.

Entwickelt in Zusammenarbeit zwischen Bundesministerium für Bildung und Forschung, deepset GmbH, GovTech Campus Deutschland e.V., Hallo Welt! GmbH und dem Fraunhofer IVV.

---Mit der Anbindung eines Large Language Model wird der Zugriff auf Inhalte eines Wikis personenunabhängiger, benutzerfreundlicher und inklusiver.---

Die Hallo Welt! GmbH bzw. GovTech Campus Deutschland e.V. unterstützt Sie gerne bei Test-Installationen und Fragen zur Weiterentwicklung bzw. zu Subskriptions-Modellen.
